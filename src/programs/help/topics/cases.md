# The Case File

The **Case File** holds every firm case, with its lead and the characters working it. Search and filter the list to find one.

Each case has:

- its **details**;
- **next actions**: the everyday work, like _Call the client_, each with who's doing it (or Unassigned) and an optional due date. Overdue ones are marked. Tick one off and it moves to **Done**, where you can reopen it; **Edit** changes it;
- **deadlines and hearings**;
- the **filings** made for it;
- **contacts** from the Rolodex, each in a role such as client or witness;
- its **evidence**: lettered exhibits (A, B, C…) with links and dates. Each exhibit has a **chain of custody** you can copy into a filing or print.

**Upcoming** lists the next 14 days, overdue first. The Case File shows a dot when something is due within 48 hours.

**Court Docket** is for judges (a title such as Judge, Justice, Magistrate or Commissioner). It lists the cases before them, soonest next date first, each one **Pending**, **Scheduled**, **Under advisement** (the status is Awaiting judgement, so a ruling is owed) or **Closed**. Filter by those, and pick a judge template and **Start** to open it with the case's details filled in.
