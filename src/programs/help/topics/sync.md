# Sync and backups

Everything is saved in this browser. Nothing leaves your computer unless you turn on sync.

## Backups

- **Back up everything** saves one file with your characters, cases, filings, drafts and settings.
- **Restore backup** puts a backup back, after showing what will change.
- Anything damaged is set aside, never deleted, and can be downloaded.
- If the browser can't open your saved data when the app starts, a notice says so and the app opens empty. Your data is still there: press **Reload** to try again. Anything you change before then isn't kept.

## Sync

Sync shares your characters, cases, filings, precedents and the rest between browsers and devices.

1. In **Settings**, under **Sync across devices**, choose **Turn on sync**. You get a **sync code**. If the site asks for an invite word, get it from whoever runs it.
2. On the other device, enter the same code to join. Capitals, spaces and dashes don't matter, and the box shows the code as it will be used. Codes never use O, 0, I or 1.

Anyone with the code can read and change that data, so keep it private. The dot in the top bar shows how sync is doing. A code nobody has used for 180 days is deleted from the server, with its data; the copies in your browsers stay.

## Install and offline

Install the app to use it like any other: on a phone, **Add to Home Screen** (Safari's Share menu, or Chrome's menu); on a computer, your browser's **Install** button in the address bar. It opens in its own window.

Once you've opened it online, it opens without a connection too. Your work is saved in this browser as always. With sync on, the dot says **Offline**, and your changes are sent when you're back online.

When a new version is ready, a notice says so. **Reload** switches to it; **What's new** shows what changed.
