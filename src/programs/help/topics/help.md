# Using Help

Help explains each program and the main things you do in the app.

- **Contents** lists every topic. Pick one to read it.
- **Search** finds the topics that hold every word you type.
- Links in a topic open another topic. **Back** returns to the one you came from.
- Every program's **Help** menu has **Help on** that program, which opens its topic.

See also: [Writing a filing](#help/filings), [Themes](#help/themes).
