# The Law Library

The **Law Library** has two pages.

- **Penal code**: browse the server's penal code by chapter or title, or search it by section number, keyword or title. Each charge shows its class, sentence and fine.
- **Precedents**: the firm's rulings, with the court, judge, key holding, summary, forum link and topics.

**Copy** a citation, such as "PC 1001 Assault", or insert it into a form from the **Form** menu in Court Filings.

See also: [Writing a filing](#help/filings).
